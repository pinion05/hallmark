HALLMARK · V1.2 PROPOSAL · FOR REVIEW · 2026-07

Five proposed themes, two alternates.

Each candidate fills a hole the current twenty themes leave open, and each is grounded in real, professionally designed sites rather than invented aesthetics. The mockups below are drawn in each candidate's draft tokens with a deliberately different structure per theme. Nothing ships until you pick.

Photography in mockups is placeholder CSS art. Fonts shown are free-baseline picks from the Hallmark canon.
Hover any mockup and click Open full page to see the theme carried through a complete landing page.
01 Plate The photograph is the page. Text is annotation. new cluster · image-led
Axes
image-carried (mid) · roman-serif-light · warm-umber
Grounded in
Aesop · SSENSE · Cereal Magazine · Airbnb Luxe
Fills the gap
No current theme can serve e-commerce, food, travel, or lookbook briefs; they all route to typography-only.
Room to play
  • Image treatment: full-bleed · inset plate · duotone wash
  • Annotation position: corner-anchored · caption rail · over-image
  • Palette derives from the photograph, not a fixed accent
Nearest existing
Photographic macrostructure exists, but no theme dresses it. Plate is its native dress + the Nanobanana hook's target.
02 Grid Swiss International style: the grid is visible and the grid is the design. editorial cluster
Axes
light · grotesk-sans (heavy) · warm-red, near-mono
Grounded in
Vitra · Braun · Vignelli canon · Museum fur Gestaltung
Fills the gap
The editorial cluster is serif-led everywhere; there is no rational, exposed-structure, grotesque voice.
Room to play
  • Column count exposed: 6 · 8 · 12; hairline weight varies
  • One red element per viewport: rule, square, or period
  • Headline case: lowercase statement vs caps specimen
Nearest existing
Manifesto (geometric poster) but Grid is rational where Manifesto is polemical; Cobalt is its dark cousin.
03 Bench The product as an engineering drawing: dimension lines, part numbers, spec chips. modern-minimal cluster
Axes
light (cool) · grotesk + mono labels · safety-orange
Grounded in
Teenage Engineering · Leica · Rimowa · DJI
Fills the gap
Hardware, devices, and physical-product briefs have no home; Workbench macro shows software, not objects.
Room to play
  • Annotation density: 2 callouts vs full exploded view
  • Object rendered as CSS art, SVG line-drawing, or photo
  • Spec chips migrate: header row · side rail · footer strip
Nearest existing
Terminal shares the mono register but is a CRT world; Bench is drawing-board daylight.
04 Maison Quiet luxury: whitespace as the asset, type barely raising its voice. editorial cluster
Axes
light (warm-white) · classical-serif · neutral (no chromatic accent)
Grounded in
The Row · Jil Sander · Byredo · Celine
Fills the gap
Atelier is crafted-warm and Lumen is night-classical; nothing does restrained fashion-house cold-press.
Room to play
  • Lockup: centered nameplate vs left-margin colophon
  • Lookbook strip: 3-up · single monolith · none
  • Tracking: from whisper (0.04em) to engraved (0.32em)
Nearest existing
The only neutral-accent theme besides austere setups; earns the centered hero exception honestly.
05 Field Warm productivity paper: the serious tool that feels hand-made. playful cluster
Axes
light (cream) · roman-serif display + humanist sans body · marigold
Grounded in
Notion · the Anthropic marketing school · Coda
Fills the gap
The biggest commercial gap: warm, credible SaaS. Hum is the only playful theme and it is rounded-consumer, not work-serious.
Room to play
  • Ink spot-illustrations: doodle density from 1 to a margin system
  • Highlighter mark on one phrase (x-height band, per gate 35)
  • Artifact props: sticky note · index card · none
Nearest existing
Almanac shares paper warmth but is archival; Field is today-at-your-desk.
A1 · alternate Ledger Fintech terminal-lux: the data is the marketing. modern-minimal cluster
Axes
dark (navy) · grotesk + tabular mono · teal
Grounded in
Mercury · Ramp · Bloomberg's density, tamed
Room to play
  • Data prop: sparkline · table · single balance
  • Navy depth band and teal restraint both tunable
Why alternate
Strong, but Cobalt + Midnight already cover cool-dark SaaS ground; picks up a slot only if you want a finance-first voice.
A2 · alternate Arcade Retro-system nostalgia: pixels, scanlines, one blinking cursor. playful cluster
Axes
dark (violet-black) · pixel display · magenta + cyan pair
Grounded in
Poolside.fm · Panic · the OP-1 generation's software
Room to play
  • CRT intensity: scanlines from whisper to heavy
  • Starfield vs flat; score-strip vs clean footer
Why alternate
Gate 47 bans re-drawn OS chrome, and this world wants windows and title bars. Shippable only with a written carve-out that keeps chrome abstract. Flagging honestly.
